Thus \((b-1)\) must divide \(k(k-1)\), and

\[
d_1 = \frac{k(k-1)}{b-1},\qquad d_0 = k - d_1.
\]

The constraints on the digits become:

- \(1 \le d_1 \le b-1\) (automatically satisfied if \(k(k-1) \ge b-1\)),
- \(0 \le d_0 \le b-1\) (automatically satisfied for the range of \(k\) we consider).

Also, for a two-digit base-\(b\) number we need:

\[
b \le k^2 \le b^2-1 \quad\Longrightarrow\quad \lceil\sqrt{b}\rceil \le k \le b-1.
\]

Hence, for a given base \(b\) (let \(m = b-1\)), the number of \(b\)-beautiful integers equals the number of integers \(k\) in the interval \([\lceil\sqrt{b}\rceil,\, m]\) such that

\[
m \mid k(k-1).
\]

---

### Counting solutions of \(m \mid k(k-1)\)

Since \(\gcd(k, k-1) = 1\), each prime power dividing \(m\) must divide either \(k\) or \(k-1\) (but not both). Let the distinct prime factors of \(m\) be \(p_1, p_2, \dots, p_\omega\). For each prime factor we have a binary choice: it divides \(k\) or it divides \(k-1\). Thus there are \(2^\omega\) residue classes modulo \(m\) that satisfy the divisibility condition.

One of these classes is \(k \equiv 0 \pmod m\) and another is \(k \equiv 1 \pmod m\). All other classes yield a unique solution \(k\) in the range \(0 \le k < m\). Consequently, the total number of solutions in the interval \([0, m]\) is \(2^\omega + 1\) (the extra solution comes from \(k=m\), which is congruent to \(0\) modulo \(m\)). Excluding the trivial solutions \(k=0,1\) (which do not satisfy \(k \ge \lceil\sqrt{b}\rceil\) for \(b\ge 2\)), the count of admissible \(k\) is essentially \(2^\omega\) (or \(2^\omega-1\) if one of the non‑trivial residues falls below \(\lceil\sqrt{b}\rceil\)).

To have **more than ten** \(b\)-beautiful integers, we need:

\[
2^\omega > 10 \quad\Longrightarrow\quad \omega \ge 4,
\]

because \(2^3 = 8\) and \(2^4 = 16\).

Thus \(m = b-1\) must have at least four distinct prime factors. The smallest integer with four distinct prime factors is:

\[
2 \times 3 \times 5 \times 7 = 210.
\]

Hence the smallest candidate base is \(b = m+1 = 211\).

---

### Verifying that \(b = 211\) yields more than ten beautiful numbers

For \(b = 211\) we have \(m = 210\) and \(\omega = 4\). The sixteen non‑trivial residue classes give the following solutions \(k\) in the interval \([15,210]\) (since \(\lceil\sqrt{211}\rceil = 15\)):

\[
\begin{aligned}
k &= 15,\,21,\,36,\,70,\,85,\,91,\,105,\,106,\\
  &\quad 120,\,126,\,141,\,175,\,190,\,196,\,210.
\end{aligned}
\]

That is **15** values of \(k\), each producing a distinct \(b\)-beautiful integer \(n = k^2\). Since \(15 > 10\), the condition is satisfied.

---

### Checking smaller bases

Any base \(b < 211\) has \(m = b-1 < 210\). Such an \(m\) cannot have four distinct prime factors (the product of the four smallest distinct primes already exceeds any smaller number). Therefore \(\omega \le 3\) for all \(b < 211\), and the maximum number of \(b\)-beautiful integers is at most \(2^3 = 8\) (or \(9\) if we count both \(k=0\) and \(k=m\)), which is insufficient.

Hence **\(b = 211\) is the smallest base with more than ten \(b\)-beautiful integers**.
